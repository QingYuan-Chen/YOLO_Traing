# 已验证示例

本页记录当前本地保存的塑料瓶训练与转换证据。它用于说明怎样记录实验，不代表不同模型之间已经完成公平排名。

## 1. 经典 YOLOv5n 320

运行目录：

```text
Training_runs/bottle/yolov5n_classic_320
```

`results.csv` 最后一条训练验证记录：

```text
epoch        199
precision    0.93372
recall       0.85354
mAP50        0.91405
mAP50-95     0.73853
```

这组数值来自训练过程的验证记录，不应和使用其他 split 或其他参数得到的测试集结果混为一谈。

## 2. YOLOv8n 640

当前归档目录：

```text
Training_runs/bottle/yolov8n_640
```

`results.csv` 最后一条记录：

```text
epoch        200
precision    0.94692
recall       0.86287
mAP50        0.91940
mAP50-95     0.78375
```

该运行使用的主要参数记录为：

```text
model    yolov8n.pt
epochs   200
batch    16
imgsz    640
device   0
workers  0
```

原始 `args.yaml` 中保存的旧 `save_dir` 与当前归档目录不同，说明结果后来经过目录整理。判断实验来源时应同时保留 `args.yaml`、`results.csv`、权重哈希和迁移记录，不能只看当前文件夹名称。

## 3. 为什么不能直接比较上面两行 mAP

两个示例至少存在输入尺寸和训练入口差异：

- 经典 YOLOv5n 使用 320 输入。
- YOLOv8n 使用 640 输入。

只有使用同一数据集版本、同一 split、同一输入尺寸和同一评估命令，才能用于严格模型比较。

## 5. 推荐的实验记录

每次正式训练至少保留：

- 启动命令。
- Python、PyTorch、CUDA 和框架版本。
- 数据集版本与样本数量。
- 初始权重 SHA-256。
- `args.yaml`、`results.csv`、日志。
- `best.pt`、`last.pt` 的 SHA-256。
- 验证命令和完整指标。
- 文件移动、重命名或转换记录。
